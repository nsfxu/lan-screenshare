A small fix that makes watching smoother: the brief freeze viewers saw about once a minute is gone. If you have 2.2.0 on Windows, this version downloads by itself; click **Restart to update** when the title bar offers it.

## Download

| System | File |
|---|---|
| **Windows 10/11**, most PCs | `ScreenShare-Setup-2.2.1-x64.exe` |
| **Windows 11 on ARM** (e.g. Snapdragon laptops) | `ScreenShare-Setup-2.2.1-arm64.exe` |

| **Mac with Intel**, experimental | `ScreenShare-2.2.1-x64.dmg` |

Works in the same rooms as other 2.x versions, so people can update when they like.

## What's new

#### Fixed

- **No more short freeze about once a minute** when watching a shared desktop at full size. Every minute or so the stream sends a full picture, and it used to arrive slowly enough to stall the video for a moment (0.2–0.9 s); it now arrives without a pause.

The installers aren't code-signed yet: on Windows click **More info → Run anyway**, on macOS right-click the app → **Open** the first time.

Full list of changes: [CHANGELOG.md](https://github.com/nsfxu/lan-screenshare/blob/main/CHANGELOG.md)

## 🇧🇷 Em português

Uma correção pequena que deixa a transmissão mais suave: a travadinha que os espectadores viam mais ou menos uma vez por minuto acabou.

- **Corrigido**: ao assistir uma área de trabalho compartilhada em tamanho cheio, a imagem não trava mais por um instante (0,2–0,9 s) a cada minuto. De tempos em tempos a transmissão envia uma imagem completa, que chegava devagar o bastante para parar o vídeo; agora ela chega sem pausa.

Quem tem a 2.2.0 no Windows recebe esta versão sozinho: clique em **Restart to update** quando a barra de título oferecer. Funciona nas mesmas salas que as outras versões 2.x. Os instaladores ainda não são assinados: no Windows clique em **Mais informações → Executar assim mesmo**; no macOS, clique com o botão direito no app → **Abrir** na primeira vez.
