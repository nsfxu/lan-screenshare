## Download

| System | File |
|---|---|
| **Windows 10/11**, most PCs | `ScreenShare-Setup-2.9.0-x64.exe` |
| **Windows 11 on ARM** (e.g. Snapdragon laptops) | `ScreenShare-Setup-2.9.0-arm64.exe` |
| **Mac with Apple Silicon** (M1 or newer), experimental | `ScreenShare-2.9.0-arm64.dmg` |
| **Mac with Intel**, experimental | `ScreenShare-2.9.0-x64.dmg` |

The `.zip` files and `latest-mac.yml` are for Macs updating themselves; you don't need to download them.

Works in the same rooms as other 2.x versions, so people can update when they like. On Windows, 2.2.0 and later update themselves: look for **Restart to update** in the title bar.

**On a Mac, download this version by hand once**: older Mac versions can't update themselves into it. Put it in your **Applications** folder, open it, and allow Screen Recording one last time (*System Settings → Privacy & Security → Screen & System Audio Recording*: if ScreenShare is already listed, remove it with **–** first, then allow it again and restart the app). From then on, new versions arrive by themselves.

## What's new

#### Added

- **The Mac app updates itself.** Like on Windows, a new version downloads in the background and **Restart to update** appears in the title bar; nothing installs until you click it. It works from this version on, for ScreenShare in your Applications folder: download this one by hand once. Run from the disk image or Downloads, the app keeps offering the download page instead.

#### Changed

- **macOS remembers the Screen Recording permission across updates.** Until now every update made macOS forget it: the switch still looked on, but sharing showed only your wallpaper and ScreenShare's own windows until you removed ScreenShare from the list and allowed it again. The Mac app is now signed with the project's own certificate, so after updating to this version you allow it one last time (macOS may also ask once more for Local Network access).

The installers aren't signed with a certificate Windows or Apple trusts yet: on Windows click **More info → Run anyway**, on macOS open the app once, click **Done**, then **Open Anyway** in *System Settings → Privacy & Security* ([step by step](https://github.com/nsfxu/lan-screenshare/blob/main/docs/en-US/user-guide.md#opening-it-for-the-first-time-on-macos)).

## 🇧🇷 Em português

O 2.9.0 traz:

- **O app do Mac se atualiza sozinho.** Como no Windows, a versão nova baixa em segundo plano e **Reinicie para atualizar** aparece na barra de título; nada é instalado até você clicar. Funciona com o ScreenShare na pasta **Aplicativos**.
- **O macOS lembra a permissão de Gravação de Tela entre atualizações.** Até agora, cada atualização fazia o macOS esquecer a permissão: a chave parecia ligada, mas o compartilhamento mostrava só o papel de parede e as janelas do próprio ScreenShare. O app do Mac agora é assinado com o certificado do projeto.

**No Mac, baixe esta versão à mão uma vez**: as versões antigas do Mac não conseguem se atualizar para ela. Coloque-a na pasta **Aplicativos**, abra e permita a Gravação de Tela uma última vez (*Ajustes do Sistema → Privacidade e Segurança → Gravação de Tela e Áudio do Sistema*: se o ScreenShare já estiver na lista, tire-o com **–** antes, permita de novo e reinicie o app). Depois disso, as versões novas chegam sozinhas. Os arquivos `.zip` e `latest-mac.yml` são para essas atualizações; você não precisa baixá-los.

Funciona nas mesmas salas que as outras versões 2.x. No Windows, quem tem o 2.2.0 ou mais novo recebe a atualização sozinho (**Reinicie para atualizar**). No macOS, na primeira vez feche o aviso e clique em **Abrir Mesmo Assim** em *Ajustes do Sistema → Privacidade e Segurança* ([passo a passo](https://github.com/nsfxu/lan-screenshare/blob/main/docs/pt-BR/user-guide.md#abrir-pela-primeira-vez-no-macos)). No Windows, clique em **Mais informações → Executar assim mesmo**.
