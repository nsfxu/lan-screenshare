## What's new

#### Added

- **Automatic updates on Windows**: the app looks for a new version every few hours, downloads it in the background, and shows **Restart to update** in the title bar when it's ready. You choose when to restart (it asks first if you're in a room); nothing installs by itself when you close the app. On macOS the title bar offers **Update to …**, which opens the download page. Turn it off in **Settings → About**, where **Check now** also is. This is the only thing the app does on the internet. From this version on, you won't need to download new versions by hand on Windows.

The installers aren't code-signed yet: on Windows click **More info → Run anyway**, on macOS right-click the app → **Open** the first time.

Full list of changes: [CHANGELOG.md](https://github.com/nsfxu/lan-screenshare/blob/main/CHANGELOG.md)

## 🇧🇷 Em português

O ScreenShare agora se mantém atualizado. **Esta é a última versão que você baixa à mão no Windows**: daqui para frente, as versões novas baixam em segundo plano e são instaladas quando você clica em **Restart to update**.

- **Windows**: o app procura uma versão nova a cada algumas horas, baixa em segundo plano e mostra **Restart to update** na barra de título quando ela está pronta. Você escolhe quando reiniciar (ele pergunta antes se você está numa sala); nada é instalado sozinho quando você fecha o app.
- **macOS**: a barra de título mostra **Update to …**, que abre a página de download.
- Dá para desligar em **Settings → About**, onde também fica o **Check now**. É a única coisa que o app faz na internet.

Funciona nas mesmas salas que as versões 1.x e 2.x. Os instaladores ainda não são assinados: no Windows clique em **Mais informações → Executar assim mesmo**; no macOS, clique com o botão direito no app → **Abrir** na primeira vez.
